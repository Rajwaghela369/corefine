# COD 1000057 — lanthanum hexaboride (Pm-3m, a = 4.1570 Å)

Single-crystal X-ray structure (Kristallografiya, 1986: "X-ray structural investigation of single crystals of
lanthanum, cerium, and samarium hexaborides"), used to index the SRM 660c reflections. CsCl-type arrangement of
La and B₆ octahedra, 7 atoms per cell.
